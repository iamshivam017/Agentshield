# AgentShield ML

Machine-learning pipeline for the single Track 2 loss class: unauthorized/anomalous agent-initiated transactions.

Planned stages:

1. Synthetic data generation
2. Temporal feature engineering
3. Chronological train/validation/test split
4. Baseline and candidate model training
5. Threshold and cost analysis
6. Calibration/evaluation
7. Artifact versioning and checksum
8. Serving contract

The held-out test set remains frozen for final evaluation.
